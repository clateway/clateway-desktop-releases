# Clateway Insights for Mac and Windows

Installers of the Clateway Insights desktop app (beta). Download them from [clateway.ai/download](https://clateway.ai/download).

- **macOS** 12 or later, Apple silicon and Intel: `Clateway-Insights-mac.dmg`
- **Windows** 10 and 11: `Clateway-Insights-Setup.exe`

Installed apps update themselves from the releases here. The source code is not in this repository.
